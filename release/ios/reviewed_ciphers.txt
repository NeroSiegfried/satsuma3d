# Cipher code in the iPad app that is not the operating system's and not a general encryption
# library, reviewed one family at a time (ROUND5 8M.2, E6; decisions 98-99). Read by
# `check_no_encryption_library.py`: a defined symbol whose name names a cipher and that matches no
# line here is "unreviewed", and an unreviewed symbol keeps the tester build from claiming anything
# about encryption. A library update that brings a new cipher in therefore shows up as unreviewed
# until someone reads it and adds a line with its reason.
#
# One line per family: `<group> | <library> | <family> | <pattern> | <reason>`.
#   group    `format`: a cipher inside a media or document library (listed every time, never a pass
#            for claiming "no encryption" by itself: the claim is the owner's, ENCRYPTION_CLAIM);
#            `not a cipher`: a name that only looks like one, with why.
#   pattern  a Python regular expression matched whole against the demangled name, without Mach-O's
#            leading underscore. Keep each one narrow: it hides what it matches.
# How each format cipher could be reached in this app, read in the code: Blender iPad
# evidence/2026-11-19-encryption/format-ciphers-reach.md (8M.2, E8).
#
# Reviewed 2026-11-19 against the tester build of 9ffb6d74682 (the main program and its 40
# libraries); the library each symbol comes from was read in lib/ios_arm64 with `nm -A`.
