# Every operator that runs modally without a modal key map (ROUND6 MODE-5, finding C9): its
# `modal()` reads keys itself, which the modal bar does not see in a key map. Each says how a finger
# reaches what its keys do. Macros are not listed: their steps' own key maps apply.
#
# One line per operator: `<idname> | <how>: <why>`, where how is one of
#   status  - it writes its keys in the status bar, which the modal bar shows as buttons;
#   drag    - it follows the press and ends with it or with the bar's Confirm and Cancel;
#   job     - it watches a job, which Escape or the busy veil's Stop ends;
#   desktop - a key it reads has no button: said here, and in MODE-6's table of key-only commands;
#   none    - not in this build.
#
# `tests/python/bl_native_shell_sources.py` asks Blender for the list
# (`WM_native_ui_modal_without_keymap`) and fails on one not here, and on one here that is gone.
